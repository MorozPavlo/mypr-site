# MyPR — website

Static site for the MyPR iOS app: marketing landing, support, and privacy policy.
Hosted free on GitHub Pages.

- **Marketing / home:** `index.html`
- **Support (App Store Support URL):** `support.html`
- **Privacy Policy:** `privacy.html`

Pure static HTML/CSS — no build step, no backend. Edit the `.html` files directly.

## Live URLs

- Home: https://morozpavlo.github.io/mypr-site/
- Support: https://morozpavlo.github.io/mypr-site/support.html
- Privacy: https://morozpavlo.github.io/mypr-site/privacy.html

Currently Ukrainian only; English and French versions to follow.
